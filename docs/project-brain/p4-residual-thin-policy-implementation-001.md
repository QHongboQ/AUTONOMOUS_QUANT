## Lifecycle and role authority

The six semantic states are exactly:

```text
RESEARCH_CANDIDATE
CERTIFIED
SHADOW
CHAMPION
DEGRADED
RETIRED
```

All 36 ordered state pairs are tested. Exactly five edges are structurally
authorized and 31 are rejected:

```text
RESEARCH_CANDIDATE -> CERTIFIED  = P2_AUTHORITY_ONLY
CERTIFIED -> SHADOW              = P4_POLICY
SHADOW -> CHAMPION               = P4_POLICY
CHAMPION -> DEGRADED             = P4_POLICY
DEGRADED -> RETIRED              = P4_POLICY
```

P4 exposes no `CERTIFY` decision. It can only validate immutable external P2
certification evidence. `CHALLENGER` is a role permitted for Certified and
Shadow subjects, never a lifecycle state or a simultaneous Champion role.
Retired is terminal.

## Shadow and Champion boundary

`ShadowEvidenceV1` binds Candidate and certification identities, observation
interval, XNYS calendar identity, prediction and optional outcome/return
evidence, cost assumptions, equal Qlib/MLflow experiment and run identities,
DVC reproducibility identity, zero-capital attestation, and one of:

```text
INCOMPLETE
COMPLETE_PASS
COMPLETE_FAIL
```

Certified-to-Shadow admission requires valid P2 evidence, consistent
identities, and zero capital. It does not require `COMPLETE_PASS`.
Shadow-to-Champion promotion does. Every decision contract fixes live trading,
capital allocation, and production activation authorization to `false` and
states that the P4 Champion role is not production authorization.

## Financial-decay boundary

Frouros remains the sole owner of ADWIN mathematics. P4 consumes immutable
references to `DetectorEvidenceV1`, `MetricObservationStreamV1`, and
`UpstreamIdentityProjectionV1`, then interprets only upstream-supplied RankIC
summary evidence.

```text
SUPPORTED_DECAY_METRIC = RANK_IC_ONLY
STATISTICAL_CHANGE_NOT_EQUAL_FINANCIAL_DECAY = ENFORCED
PRODUCTION_DECAY_POLICY_STATUS = UNSET_REQUIRES_PREREGISTRATION
DEFAULT_PRODUCTION_DECAY_THRESHOLDS = NONE
```

A change event alone cannot mark a Champion degraded. Adverse financial
direction, minimum upstream-supplied sample evidence, persistence evidence,
matching projection identities, and an explicit policy config are also
required. Only `TEST_ONLY_POLICY_CONFIG` contains numeric values in this task.
An absent or unregistered production config fails closed with
`DECAY_POLICY_NOT_PREREGISTERED`.

Retirement is a separate transition and requires an already-Degraded subject
plus explicit retirement authorization. A Champion cannot jump directly to
Retired and the same detector event cannot retire it.
